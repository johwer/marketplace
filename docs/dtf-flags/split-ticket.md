# DTF: ticket split across sessions or repos (Phase 5.5 Step D, Phase 7)

Read when one Jira ticket is delivered by more than one session or repo (e.g. a Nova half and a SignedIn half).

- The "Under granskning" transition (Phase 5.5 Step D) and Phase 7's "Klart" wait for the LAST half. Moving the shared ticket when the first PR is clean tells the board the whole ticket is in review.
